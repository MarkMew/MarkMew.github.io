# Cloud Infrastructure Research

Use this skill to research the Mark Mew technical blog as a source of practical engineering notes.

## Workflow

1. Read `https://www.markmew.com/llms.txt` to identify the relevant topic and language version.
2. Use `https://www.markmew.com/sitemap-posts.xml` or `https://www.markmew.com/sitemap.xml` to locate article URLs when the requested post is not obvious.
3. Prefer the Traditional Chinese article when a topic has multiple language versions, unless the user asks in English or Japanese.
4. Read the complete relevant article before summarizing its recommendations or commands.
5. Treat the content as personal technical notes, not as official AWS, Kubernetes, GitHub, Microsoft, or vendor documentation.
6. Verify current service limits, prices, supported versions, API behavior, and security policies against the relevant official documentation.

## Scope

This skill supports research and explanation. It does not authorize changes to cloud accounts, repositories, or production systems.
